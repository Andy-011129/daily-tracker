# Daily Tracker（iPhone 可安装网页应用）

## 文件
- index.html：计时器应用
- manifest.webmanifest：主屏幕安装配置
- sw.js：离线缓存
- icon-192.png / icon-512.png：应用图标

## 安装到 iPhone
1. 将整个文件夹部署到支持 HTTPS 的静态网站托管服务（例如 GitHub Pages、Netlify 等）。必须保留文件夹结构。
2. 在 iPhone 上用 Safari 打开部署后的 HTTPS 地址。
3. 点 Safari「分享」→「添加到主屏幕」→「添加」。
4. 从主屏幕图标打开应用。建议先点击「开启 23:00 提醒」并允许通知。

## 重要限制
- 数据使用浏览器 localStorage，仅保存在当前 iPhone/浏览器；清除 Safari 网站数据会删除记录。
- 计时用时间戳累计，切换应用、锁屏、关闭页面后重新打开会按实际经过时间补算；不依赖后台每秒运行。
- 由于 iOS 对网页应用后台执行的限制，当前版本不能保证应用完全关闭时在 23:00 准时发出通知。应用在前台运行时会检查 23:00 并提醒。若必须在关闭 App 后也可靠提醒，需要改为原生 iOS App（本地通知）。
- 当前版本不会上传或同步数据。建议定期导出/备份功能作为后续增强。
